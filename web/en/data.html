Reproduce it

The calculation is deterministic: D’Hondt and the weighting use no random seed. To reproduce a build you need the code, the frozen input CSV and the same parameters.

git clone https://github.com/mcasrom/elecciones29n-osint
cd elecciones29n-osint
bash scripts/reproduce.sh /tmp/e29n-repro

The script rebuilds from the current data/polls_history.csv and prints SHA-256 hashes. For a historical build, freeze that CSV and the input JSON first.
