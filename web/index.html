Senado

no se simula

El Senado tiene 265 escaños: 208 electos en circunscripción provincial (4 por provincia, con excepciones insulares) y 57 designados por las comunidades autónomas.

No aplico una simulación porque el reparto depende de listas provinciales y de mayorías autonómicas, no de una media nacional. Cualquier cifra nacional sería un artefacto. Si aparece, se mostrará como referencia vigente y nunca como proyección.

Por qué el Congreso sí y el Senado no

El Congreso se puede aproximar con D'Hondt sobre una media nacional para ver el tamaño de los bloques, con todas las cautelas. El Senado se elige con listas abiertas y mayoritario plurinominal por provincia: una media nacional no informa del reparto. Simularlo daría una falsa precisión.
