Fuente, método y límites

  • Fuente: CIS · estudio 3582, Barómetro de octubre 2026 (publicado el 2026-10-14; muestra 5.025). Cruces por edad, sexo y escala de ideología.
  • Base: Voto declarado en las elecciones generales de 2023. Porcentajes sobre voto a partidos (excluye blanco, nulo, no votantes y no respuesta). N ponderado.
  • Celdas pequeñas: n<30 se suprimen; no se estiman valores a partir de ellas.
  • Ideología: 1–4 izquierda, 5–6 centro, 7–10 derecha; se agregan para tener n suficiente.
  • Límites: voto declarado (no real), N ponderado, categorías de una sola encuesta, sin causalidad. No se cruza el censo con el voto.

Cómo leer el observatorio

  1. Sondeos ≠ pronóstico. Es la media de los sondeos publicados, con rango mínimo–máximo. El rango no es un intervalo de confianza.
  2. Tres capas distintas. Quién puede votar (censo), quién vota (participación) y cómo se traduce (territorio).
  3. Datos oficiales. Censo (INE), participación (JEC) y escaños (BOE) no son estimaciones. Los sondeos sí.
  4. Lo que no dice. No predice el resultado ni atribuye preferencias por edad, sexo o territorio.
